# @soio/web — Loja pública

**URL:** https://loja.soio.com.br  
**Dev:** http://localhost:3000

## Comandos (na raiz do monorepo)

```bash
npm install
npm run dev
```

## Variáveis

Copie `.env.local.example` para `.env.local`.

## Stack

- Next.js 16 (App Router)
- Tailwind CSS 4
- `@soio/shared` (constantes e regras de negócio)
